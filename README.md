# Python for Machine Learning – NumPy Fundamentals

## Project Overview

This project is part of the Cynaris AI/ML Internship – Week 1 assignment. It demonstrates fundamental NumPy concepts through practical Python examples used in Machine Learning.

## Technologies Used

- Python 3.13
- NumPy
- Pandas
- Scikit-Learn

## Project Structure

```text
cynaris-internship-pallavi/
├── .venv/
├── data/
│   └── iris.csv
├── src/
│   └── numpy_fundamentals.py
├── tests/
├── .gitignore
├── README.md
└── requirements.txt
```

## Practical Tasks Completed

1. Created 1D, 2D and 3D NumPy arrays and verified their shapes.
2. Demonstrated NumPy broadcasting.
3. Performed vectorised arithmetic operations without Python loops.
4. Performed matrix multiplication using NumPy.
5. Calculated mean, standard deviation and correlation using the Iris dataset.

## Environment Setup

### 1. Create a virtual environment

```bash
python3 -m venv .venv
```

### 2. Activate the virtual environment

For macOS/Linux:

```bash
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Run the Project

```bash
python src/numpy_fundamentals.py
```

## Dataset

The Iris dataset is stored in `data/iris.csv`. NumPy loads the numeric features to calculate statistical measurements.

## Learning Outcomes

- Understanding NumPy arrays and dimensions.
- Applying broadcasting and vectorised operations.
- Performing matrix multiplication.
- Calculating statistical measures from a real dataset.
- Managing project dependencies using a virtual environment.
